プライバシーポリシー

昆虫大戦（BEETLE WARS）／最終更新日: 2026年8月11日

本ポリシーの要旨
本アプリは、氏名・メールアドレス・電話番号を取得しません。広告およびアクセス解析は導入していません。 セーブデータを保護する目的で、初回起動時に ランダムな匿名ID を Google（Firebase）から取得します。 セーブデータは利用者の端末に保存され、利用者が「バックアップ」を実行した場合に限り、クラウドにも控えを保存します。 控えおよび匿名IDはアプリ内からいつでも削除できます。

2. 取得しないもの

本アプリは、氏名・メールアドレス・電話番号・住所・生年月日・位置情報・連絡先・写真・端末の識別子（IDFA / 広告ID を含む）を取得しません。広告も、アクセス解析（Google Analytics 等）も、クラッシュレポートの収集も導入していません。

3. 取得するもの

セーブデータを保護する目的で、次の情報を取り扱います。取り扱う情報は以下のとおりであり、これ以外にはありません。

取得するもの内容いつ
匿名ID ランダムな文字列。氏名・メールアドレス・端末の識別子とは結び付いていません。誰であるかは分かりません 初回起動時に自動
IPアドレス 通信の性質上、接続先（Google）に伝わります。開発者はこれを保存・閲覧していません 通信のたび
セーブデータ 下の表の内容（プレイヤー名・進行状況など） 利用者が「バックアップ」を実行したときのみ

これらは Google LLC が提供する Firebase Authentication および Cloud Firestore に保存されます。保存場所は東京リージョン（asia-northeast1）です。

匿名IDについて。アカウント登録ではありません。メールアドレスもパスワードも入力しません。 「この端末のデータ」と「クラウドの控え」を結び付けるためだけの、意味を持たないランダムな文字列です。
クラウドの控えは、あなた以外は開けません。保存先には「そのIDの本人しか読み書きできない」設定 （Firestore セキュリティルール）を入れており、他の利用者からは読めません。 開発者は管理者権限で内容を見ることが技術的には可能ですが、不具合の調査など必要な場合に限ります。
削除できます。アプリ内の「設定 → データ引き継ぎ → クラウドのデータを削除する」から、 クラウドの控えと匿名IDをまとめて削除できます。削除後は次の起動で新しい匿名IDが振られます。 メールでのご依頼も受け付けます。

アプリが端末内に保存するもの

次のデータを、OS がアプリごとに割り当てた領域（他のアプリから読めない場所）に保存します。

保存されるもの内容
セーブデータプレイヤー名（初期値「プレイヤー」）、ゲーム内で自動生成されるユーザーID、レベル、所持している甲虫・技カード・素材、ゲーム内通貨（コイン・ジュエル）、進行状況、ミッションの達成状況
設定音量、演出スキップ、触覚フィードバックの入切
撮影した画像ホーム画面の「撮影」で保存した PNG 画像
アプリ内に表示される BW-XXXXXXXX について。これは端末内で自動生成される、表示用のIDです。 上の匿名IDとは別のもので、氏名やメールアドレス、端末の識別子とは結び付いていません。
「撮影」機能について。画面の画像はアプリ専用の領域に保存されます。カメラロール（写真ライブラリ）への保存には対応していないため、 写真へのアクセス許可を求めることはありません。カメラも使用しません。
データの消失について。アプリを削除すると、端末内のセーブデータは消えます。 「バックアップ」を押していれば、同じ端末ならクラウドの控えから戻せます。 ただし 機種変更でのデータ移行（Apple / Google アカウントの紐づけ）は、現時点でまだ実装していません。 別の端末では控えを取り出せませんので、あらかじめご了承ください。実装したときは本ページを改定します。

アプリが求める権限

本アプリは、位置情報・カメラ・マイク・写真・連絡先・カレンダー・ヘルスケア・トラッキング許可（App Tracking Transparency）のいずれについても、許可を求めません。

ネットワーク通信は行います（上の「取得するもの」のとおり）。通信できない状態でも、ストーリー・周回クエスト・闘技場・ガチャはそのまま遊べます。

4. アプリ内課金について

本アプリは今後、アプリ内課金（ゲーム内通貨「ジュエル」の購入）を提供する予定です。課金に関する決済は、すべて Apple（App Store）または Google（Google Play）の仕組みを通じて行われます。

  • クレジットカード番号などの決済情報を開発者が取得することはありません。入力先は Apple / Google であり、開発者は内容を見ることができません。
  • 購入の有効性の確認（レシート検証）を将来サーバー側で行う場合は、本ポリシーを改定し、何を送信するのかを明記したうえで実施します。実装前に無断で送信を始めることはしません。

Apple および Google における個人情報の取り扱いは、各社のプライバシーポリシーをご確認ください。

5. 第三者提供・外部送信

上の「取得するもの」を、Google LLC（Firebase Authentication / Cloud Firestore）に保管の目的でのみ預けています。これ以外の第三者への提供や共同利用は行っていません。広告ネットワーク、アクセス解析ツール（Google Analytics 等）、クラッシュレポート収集ツールは導入していません。Google における取り扱いは同社のプライバシーポリシーをご確認ください。

法令に基づき、裁判所・捜査機関等から適法な開示要請を受けた場合には、これに応じることがあります。

6. お子さまの利用について

本アプリは昆虫を題材とした対戦ゲームであり、お子さまにもお使いいただけます。氏名・メールアドレス・生年月日を尋ねることはなく、年齢を問わず個人を特定できる情報は取得しません。

ただしアプリ内課金を含む予定です。意図しない購入を防ぐため、端末側の機能で制限をかけることをおすすめします。

  • iOS / iPadOS：設定 → スクリーンタイム → コンテンツとプライバシーの制限 → 「App内課金」を「許可しない」
  • Android：Google Play → 設定 → 認証 → 「購入時には認証を必要とする」
