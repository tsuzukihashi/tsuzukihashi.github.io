プライバシーポリシー

昆虫大戦（BEETLE WARS）／最終更新日: 2026年8月11日

本ポリシーの要旨
本アプリは、氏名・メールアドレス・電話番号を取得しません。広告およびアクセス解析は導入していません。 セーブデータを保護する目的で、初回起動時に ランダムな匿名ID を Google（Firebase）から取得します。 セーブデータは利用者の端末に保存され、利用者が「バックアップ」を実行した場合に限り、クラウドにも控えを保存します。 控えおよび匿名IDはアプリ内からいつでも削除できます。

1. 事業者

提供者續橋涼（個人開発者 / TsuzuKit）
アプリ名昆虫大戦（BEETLE WARS）
対象プラットフォームiOS / iPadOS / Android
連絡先ryo.tsuzukihashi@tsuzukit.com

本ポリシーは、上記アプリおよび本アプリの紹介ページ（https://tsuzukit.com/beetlewars/ 配下）を対象とします。

2. 取得しないもの

本アプリは、氏名・メールアドレス・電話番号・住所・生年月日・位置情報・連絡先・写真・端末の識別子（IDFA / 広告ID を含む）を取得しません。広告も、アクセス解析（Google Analytics 等）も、クラッシュレポートの収集も導入していません。

3. 取得するもの

セーブデータを保護する目的で、次の情報を取り扱います。取り扱う情報は以下のとおりであり、これ以外にはありません。

取得するもの内容いつ
匿名ID ランダムな文字列。氏名・メールアドレス・端末の識別子とは結び付いていません。誰であるかは分かりません 初回起動時に自動
IPアドレス 通信の性質上、接続先（Google）に伝わります。開発者はこれを保存・閲覧していません 通信のたび
セーブデータ 下の表の内容（プレイヤー名・進行状況など） 利用者が「バックアップ」を実行したときのみ

これらは Google LLC が提供する Firebase Authentication および Cloud Firestore に保存されます。保存場所は東京リージョン（asia-northeast1）です。

匿名IDについて。アカウント登録ではありません。メールアドレスもパスワードも入力しません。 「この端末のデータ」と「クラウドの控え」を結び付けるためだけの、意味を持たないランダムな文字列です。
クラウドの控えは、あなた以外は開けません。保存先には「そのIDの本人しか読み書きできない」設定 （Firestore セキュリティルール）を入れており、他の利用者からは読めません。 開発者は管理者権限で内容を見ることが技術的には可能ですが、不具合の調査など必要な場合に限ります。
削除できます。アプリ内の「設定 → データ引き継ぎ → クラウドのデータを削除する」から、 クラウドの控えと匿名IDをまとめて削除できます。削除後は次の起動で新しい匿名IDが振られます。 メールでのご依頼も受け付けます。

アプリが端末内に保存するもの

次のデータを、OS がアプリごとに割り当てた領域（他のアプリから読めない場所）に保存します。

保存されるもの内容
セーブデータプレイヤー名（初期値「プレイヤー」）、ゲーム内で自動生成されるユーザーID、レベル、所持している甲虫・技カード・素材、ゲーム内通貨（コイン・ジュエル）、進行状況、ミッションの達成状況
設定音量、演出スキップ、触覚フィードバックの入切
撮影した画像ホーム画面の「撮影」で保存した PNG 画像
アプリ内に表示される BW-XXXXXXXX について。これは端末内で自動生成される、表示用のIDです。 上の匿名IDとは別のもので、氏名やメールアドレス、端末の識別子とは結び付いていません。
「撮影」機能について。画面の画像はアプリ専用の領域に保存されます。カメラロール（写真ライブラリ）への保存には対応していないため、 写真へのアクセス許可を求めることはありません。カメラも使用しません。
データの消失について。アプリを削除すると、端末内のセーブデータは消えます。 「バックアップ」を押していれば、同じ端末ならクラウドの控えから戻せます。 ただし 機種変更でのデータ移行（Apple / Google アカウントの紐づけ）は、現時点でまだ実装していません。 別の端末では控えを取り出せませんので、あらかじめご了承ください。実装したときは本ページを改定します。

アプリが求める権限

本アプリは、位置情報・カメラ・マイク・写真・連絡先・カレンダー・ヘルスケア・トラッキング許可（App Tracking Transparency）のいずれについても、許可を求めません。

ネットワーク通信は行います（上の「取得するもの」のとおり）。通信できない状態でも、ストーリー・周回クエスト・闘技場・ガチャはそのまま遊べます。

4. アプリ内課金について

本アプリは今後、アプリ内課金（ゲーム内通貨「ジュエル」の購入）を提供する予定です。課金に関する決済は、すべて Apple（App Store）または Google（Google Play）の仕組みを通じて行われます。

  • クレジットカード番号などの決済情報を開発者が取得することはありません。入力先は Apple / Google であり、開発者は内容を見ることができません。
  • 購入の有効性の確認（レシート検証）を将来サーバー側で行う場合は、本ポリシーを改定し、何を送信するのかを明記したうえで実施します。実装前に無断で送信を始めることはしません。

Apple および Google における個人情報の取り扱いは、各社のプライバシーポリシーをご確認ください。

5. 第三者提供・外部送信

上の「取得するもの」を、Google LLC（Firebase Authentication / Cloud Firestore）に保管の目的でのみ預けています。これ以外の第三者への提供や共同利用は行っていません。広告ネットワーク、アクセス解析ツール（Google Analytics 等）、クラッシュレポート収集ツールは導入していません。Google における取り扱いは同社のプライバシーポリシーをご確認ください。

法令に基づき、裁判所・捜査機関等から適法な開示要請を受けた場合には、これに応じることがあります。

6. お子さまの利用について

本アプリは昆虫を題材とした対戦ゲームであり、お子さまにもお使いいただけます。氏名・メールアドレス・生年月日を尋ねることはなく、年齢を問わず個人を特定できる情報は取得しません。

ただしアプリ内課金を含む予定です。意図しない購入を防ぐため、端末側の機能で制限をかけることをおすすめします。

  • iOS / iPadOS：設定 → スクリーンタイム → コンテンツとプライバシーの制限 → 「App内課金」を「許可しない」
  • Android：Google Play → 設定 → 認証 → 「購入時には認証を必要とする」

7. 本紹介ページ（Webサイト）について

本ページは GitHub Pages（GitHub, Inc.）でホスティングしています。ページ自体に Cookie を用いた追跡や、アクセス解析タグは設置していません。ただし、以下の点をご承知ください。

  • ホスティング事業者のサーバーには、通常のWebサイトと同様に、アクセス日時・IPアドレス・ブラウザの種類などが技術的な記録として残る場合があります。開発者はこれを閲覧・分析していません。
  • 本ページは表示に Google Fonts（Google LLC）を使用しています。フォントの読み込みの際、お使いの端末のIPアドレスが Google に送信されます。
  • 本ページから外部サイト（App Store、Google Play 等）へ移動された場合、移動先での情報の取り扱いは各サイトの方針に従います。

8. お問い合わせでお預かりする情報

メールでお問い合わせいただいた場合、返信のために、メールアドレスとご記入いただいた内容をお預かりします。これらはお問い合わせへの対応と不具合の修正のためにのみ使用し、第三者に提供しません。対応が完了し、保管の必要がなくなった時点で削除します。

9. 安全管理

お預かりしたお問い合わせ内容には、開発者本人のみがアクセスします。アプリのセーブデータについては、OS がアプリごとに分離した領域に保存する仕組みに従っており、他のアプリから読み取ることはできません。

10. 開示・訂正・削除のご請求

クラウドに預けた控えと匿名IDは、アプリ内の「設定 → データ引き継ぎ → クラウドのデータを削除する」からご自身で削除できます。メールでのご依頼も受け付けます。

開発者は氏名・メールアドレス等を保有していないため、それらの開示・訂正の対象となる情報はありません。お問い合わせのメールについて削除をご希望の場合も、下記の連絡先までお知らせください。

Summary of this policy
This app does not collect your name, email address, or phone number. It contains no ads and no analytics. To protect your save data, it obtains a random anonymous ID from Google (Firebase) on first launch. Save data is stored on your device, and a copy is also stored in the cloud only if you run "Back Up". You can delete the cloud copy and the anonymous ID from within the app at any time.

1. Provider

ProviderRyo Tsuzukihashi (independent developer / TsuzuKit)
App nameBeetle Wars
PlatformsiOS / iPadOS / Android
Contactryo.tsuzukihashi@tsuzukit.com

This policy applies to the app above and to its introduction pages (under https://tsuzukit.com/beetlewars/).

2. What we do not collect

This app does not collect your name, email address, phone number, postal address, date of birth, location, contacts, photos, or device identifiers (including IDFA / advertising ID). It includes no advertising, no analytics (such as Google Analytics), and no crash report collection.

3. What we collect

To protect your save data, the app handles the following information. This is the complete list; nothing else is handled.

WhatDetailsWhen
Anonymous ID A random string. It is not linked to your name, email address, or device identifiers, and it does not reveal who you are Automatically on first launch
IP address By the nature of network communication, it reaches the destination (Google). The developer does not store or view it Each time the app communicates
Save data The contents listed in the table below (player name, progress, and so on) Only when you run "Back Up"

This information is stored in Firebase Authentication and Cloud Firestore, provided by Google LLC. The storage location is the Tokyo region (asia-northeast1).

About the anonymous ID. This is not account registration. You do not enter an email address or password. It is a meaningless random string used only to link "the data on this device" with "the copy in the cloud".
No one but you can open your cloud copy. The storage is configured so that only the owner of that ID can read or write it (Firestore Security Rules), and other users cannot read it. The developer is technically able to view the contents with administrator privileges, but does so only when necessary, such as when investigating a bug.
You can delete it. From Settings → Data Transfer → Delete Cloud Data in the app, you can delete the cloud copy and the anonymous ID together. After deletion, a new anonymous ID is assigned on the next launch. Requests by email are also accepted.

What the app stores on your device

The following data is stored in the area the OS assigns to each app (a place other apps cannot read).

What is storedDetails
Save dataPlayer name (default: "Player"), a user ID generated automatically in the game, level, beetles, move cards and materials you own, in-game currency (Coins and Jewels), progress, and mission completion status
SettingsVolume, effect skipping, and haptic feedback on/off
Captured imagesPNG images saved with "Capture" on the home screen
About the BW-XXXXXXXX shown in the app. This is a display ID generated automatically on your device. It is separate from the anonymous ID above and is not linked to your name, email address, or device identifiers.
About the "Capture" feature. Screen images are saved in the app's own storage area. Saving to the Camera Roll (photo library) is not supported, so the app never asks for permission to access your photos. It does not use the camera either.
About data loss. Deleting the app erases the save data on your device. If you have run "Back Up", you can restore from the cloud copy on the same device. However, transferring data to a new device (linking an Apple / Google account) has not been implemented yet. Please note that the copy cannot be retrieved on a different device. This page will be revised when that feature is implemented.

Permissions the app requests

This app does not request permission for location, camera, microphone, photos, contacts, calendar, Health, or tracking (App Tracking Transparency).

It does use network communication (as described in "What we collect" above). Even without a connection, the story, repeatable quests, arena, and gacha remain fully playable.

4. In-app purchases

This app plans to offer in-app purchases (buying the in-game currency "Jewels") in the future. All payments for purchases are processed through Apple (App Store) or Google (Google Play).

  • The developer never obtains payment information such as credit card numbers. You enter it with Apple / Google, and the developer cannot see it.
  • If purchase validation (receipt verification) is performed on a server in the future, this policy will be revised first to state clearly what is sent. Sending will never begin without notice before implementation.

For how Apple and Google handle personal information, please refer to each company's privacy policy.

5. Disclosure to third parties and external transmission

The items in "What we collect" above are entrusted to Google LLC (Firebase Authentication / Cloud Firestore) solely for storage. They are not provided to or shared with any other third party. No ad networks, analytics tools (such as Google Analytics), or crash report collection tools are used. For how Google handles this information, please refer to its privacy policy.

We may comply with a lawful request for disclosure from a court, investigative authority, or similar body based on applicable law.

6. Use by children

This app is a battle game themed around insects, and children may use it. It never asks for a name, email address, or date of birth, and it does not collect personally identifiable information from users of any age.

However, it is planned to include in-app purchases. To prevent unintended purchases, we recommend setting restrictions with your device's features.

  • iOS / iPadOS: Settings → Screen Time → Content & Privacy Restrictions → set "In-app Purchases" to "Don't Allow"
  • Android: Google Play → Settings → Authentication → "Require authentication for purchases"

7. About this introduction page (website)

This page is hosted on GitHub Pages (GitHub, Inc.). The page itself does not use cookie-based tracking or analytics tags. Please note the following, however.

  • As with any ordinary website, the hosting provider's servers may keep technical records such as access time, IP address, and browser type. The developer does not view or analyze them.
  • This page uses Google Fonts (Google LLC) for display. When the fonts load, your device's IP address is sent to Google.
  • If you move from this page to an external site (App Store, Google Play, etc.), information there is handled according to that site's policies.

8. Information received through inquiries

If you contact us by email, we keep your email address and the contents of your message in order to reply. These are used only to respond to your inquiry and to fix bugs, and are not provided to third parties. They are deleted once the matter is resolved and there is no longer a need to keep them.

9. Security

Only the developer has access to the inquiries we receive. The app's save data is stored using the OS mechanism that isolates each app's storage, so other apps cannot read it.

10. Requests for disclosure, correction, or deletion

You can delete the cloud copy and anonymous ID yourself from Settings → Data Transfer → Delete Cloud Data in the app. Requests by email are also accepted.

Because the developer does not hold names, email addresses, or similar information, there is no such information subject to disclosure or correction. If you would like an inquiry email deleted, please let us know at the contact below.

11. Changes to this policy

This policy may be revised in response to changes in law or new features (such as real-time battles, data transfer, receipt verification, and other features involving network communication). If a revision increases the information collected, this page will be updated and its last-updated date changed before that feature is enabled. Important changes will also be announced in the app.
