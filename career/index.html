ZOZO 正社員 2024.08 — 現在

ZOZOTOWN / iOSエンジニア

長く運用されてきた大規模なコードベースのSwiftUI移行を、自分の案件を持ちながら進めています。 あわせてテストとCI、リリースの基盤改善と、バージョン単位のリリースマネジメントを担当。 直近1年で219本のPRを出しました。課題を自分で見つけて起案し、実装からリリースまで完結させる進め方をしています。

  • 肥大化したレガシー画面のSwiftUI全面リプレイス。稼働中の画面を止めないよう5つのフェーズに分けて置き換えた
  • 生成AIによる仕様駆動開発を自分の案件で実証し、内製ツールへ還元。実装着手前のタスク分割を設計した
  • CIの成功率とテストカバレッジの改善を主導。切り分けの難しいFlakyテストを特定して解消し、知見をチームへ展開
  • クラッシュのシンボル化が失敗しても気づけない構造を特定し、再発防止の仕組みを実装
  • ホーム画面ウィジェットを個人の試作からボトムアップで起案し、正式な社内案件として立ち上げ

Swift / Objective-C / SwiftUI / WidgetKit / App Intents / XCTest / Swift Testing / Bitrise / GitHub Actions / fastlane / Danger / SwiftLint / Firebase

DeNA 正社員 2023.02 — 2024.07

Pococha / iOSエンジニア

ライブ配信アプリのソーシャル寄りの領域を受け持ちました。 いちばん大きな担当は配信者のプロフィール動画機能で、そもそも実現できるのかという技術検証から入り、 再生基盤、投稿フロー、BGM合成、ログ設計まで一通りを担当しています。在籍中に978本のコミット。

  • スクロールで次々と動画が切り替わる体験のため、AVPlayerItemのキャッシュ機構を自前で実装し、再生開始までの待ち時間を削った
  • 動画とBGMを並列再生したときの音量バランスを、Android版と突き合わせて検証
  • SNS連携、Twitter APIの仕様変更への追従、招待コード機能のSMS認証フロー
  • Swift Concurrency対応とMainActorへの移行を推進
  • ペアプログラミングとテスト駆動開発をチーム内で実践し、Mockoloを導入

Swift / SwiftUI / AVFoundation / Swift Concurrency / Mockolo

ヤフー 正社員 2019.07 — 2023.02

PayPayフリマ / iOSエンジニア・テックリード

新卒で入社し、立ち上げ途中から参画してグロースまで携わりました。後半はテックリードとしてチームの生産性を高める役割です。 開発体制はLeanXPで、テスト駆動開発とペアプログラミングが日常。約4年で3,400本以上のコミットを積み、 リポジトリ全体で最もコミット数の多いメンバーでした。

  • 動画出品の著作権侵害対策。ShazamKitが使えない制約からiOS標準のSound Analysisによる音分類に切り替え、出品を止めずに撮影直後へ注意喚起を出す設計にした
  • ContextMenusを導入し、商品を非表示にするのに詳細画面まで進む必要があった問題を一覧から解けるようにした。ストアレビューの改善につながった
  • ユーザーフォロー、ハッシュタグフォロー、投稿機能といったソーシャル系の大規模案件
  • 出品導線、ほしい物ランキング、持ち物リスト、閲覧履歴まわり、集荷依頼、ホーム画面ウィジェット
  • SwiftPMへの移行、Snykによるライブラリ脆弱性チェック、fastlaneのリリース整備
