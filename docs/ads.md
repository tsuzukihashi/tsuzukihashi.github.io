# 広告（Google AdSense）の置き方

2026-11-17 に AdSense が承認された。広告はブログの読み物にだけ、本文の区切りに自分で置く。
**自動広告は使わない。** 管理画面（広告 > サイトごと > tsuzukit.com）でオフにしてある。

承認直後は自動広告がオンで、インテント重視のフォーマット（本文の語句を広告のリンクに変えるもの）も入っていた。
プレビューではトップページだけでページ内広告が9か所、スマホでは自己紹介のすぐ下に大きな広告が出る状態だった。

## 出すページ・出さないページ

| ページ | 広告 | 理由 |
|---|---|---|
| トップ・ポートフォリオ・About・Contact・採用 | 出さない | サイトの顔。仕事の相手が最初に見る |
| 規約・プライバシーポリシー・アプリごとのページ（`/oshiisland/` など） | 出さない | アプリの中から開かれる。課金した人にも広告を見せることになる |
| アプリ紹介の記事（`blog/posts/app-*.html`） | 出さない | 役目は自分のアプリを入れてもらうこと。中身に合わせた広告は似たアプリを出すので、取り合いになる |
| ブログの一覧・ガイドの一覧 | 出さない | カードの並びの中の広告は、記事と見分けにくい |
| 検索される問いに答える記事（ガイド、81本） | 1つ | 「どれを選ぶか」のあと、「よくある質問」の手前 |
| 収益公開（月次） | 2つ | 「分析」の手前と、締めの挨拶のあと（詳細データの手前） |
| 手書きの読み物（開発記・振り返り・前史など） | 1〜2つ | 真ん中あたりの大見出しの手前と、本文の終わり |

## 置き方の決まり

- 1記事に2つまで。最初の画面（タイトル・イラスト・先に答え）には置かない
- 置くのは見出しの手前だけ。段落の途中、アプリのカードの並びの中、表の中には置かない
- App Store へのボタンや案内の箱（`cta-box`）のすぐ隣に置かない。誤タップを誘う形になる。そういう記事は終わりの広告をやめて途中の1つだけにする
- 枠は生成りの地に「広告 / Advertisement」の札だけ。墨色の枠やずらした影は本文のカードの印なので、広告には付けない
- 埋まらなかった枠は消す。空の箱を残さない
- 「広告を押してください」「応援してください」のような、押すことを頼む言葉を書かない（AdSense のポリシー違反）

## 仕組み

- 本文の区切りに目印を置く。中身は `/assets/js/ads.js` が入れる

  ```html
  <div class="ad-slot" data-ad="mid"></div>   <!-- 記事の途中。広告ユニット 3182306220 -->
  <div class="ad-slot" data-ad="end"></div>   <!-- 本文の終わり。広告ユニット 2754930814 -->
  ```

- 日本語と英語の本文を二重に持つ記事は、両方の本文に目印を置く。`ads.js` は見えている側にだけ入れる
- 広告の形は長方形（`data-ad-format="rectangle"`、画面幅いっぱいに広げない）。高さはおよそ 250〜280px
- `localhost` では AdSense を読まず、縞模様の見本だけ出す。開発中に広告を表示させないため
- 見た目は `assets/css/blog.css` の「記事の広告枠」

## ページの `<head>`

広告を出すページ（目印のあるページ）:

```html
<!-- Google AdSense（広告は本文の .ad-slot にだけ出す。docs/ads.md） -->
<meta name="google-adsense-account" content="ca-pub-8240751277462688">
<script src="/assets/js/ads.js" defer></script>
```

広告を出さないページ（サイトの持ち主の確認のための meta だけ）:

```html
<!-- Google AdSense（持ち主の確認だけ。このページに広告は出さない。docs/ads.md） -->
<meta name="google-adsense-account" content="ca-pub-8240751277462688">
```

`adsbygoogle.js` を `<head>` に直接書かない。書くと、そのページは自動広告の対象になる（管理画面でオンに戻されたとき、規約のページにも広告が出る）。

生成スクリプトのあるページは、スクリプト側に書いてある（`scripts/build_guides.py`、`docs/income-report/generate_articles.py`、`scripts/generate_app_blogs.py`、`docs/build_ranking.py`）。

## 確かめ方

広告を出すページと目印の数が一致しているか:

```bash
A=$(git ls-files '*.html' | grep -v '^docs/' | xargs grep -l '/assets/js/ads.js' | sort)
B=$(git ls-files '*.html' | grep -v '^docs/' | xargs grep -l 'class="ad-slot"' | sort)
diff <(echo "$A") <(echo "$B") && echo 一致
```

`adsbygoogle.js` を直接読んでいるページが無いか:

```bash
git ls-files '*.html' | grep -v '^docs/' | xargs grep -l 'adsbygoogle.js'
```

## ブロックしている広告のカテゴリ（2026-11-18）

ブランド保護 > コンテンツ > ブロックのコントロール > デリケートなカテゴリ。

| カテゴリ | 状態 | 理由 |
|---|---|---|
| ダウンロード可能なユーティリティ | ブロック | 本番で最初に出たのが「ダウンロード」と大きく書いたボタン型の広告だった。App Store のバッジの近くで本物のボタンと見分けにくい |
| センセーショナルな内容・性に関する内容・ソーシャル カジノゲーム・マッチング サービス | ブロック | 家族や子どもも使うアプリを作っている人のサイトとして合わない |
| 一攫千金・消費者金融 | ブロック | 収益公開の記事の隣に出ると、記事がその宣伝に見える |
| アルコール・ギャンブル（制限付き） | ブロック | 最初からブロック済み |
| 医薬品、サプリメント・減量・美容施術、美容整形 | 許可 | 記録やリマインダーのアプリの記事と中身が近く、記事に合った広告になりやすい |
| 性と生殖に関する健康・宗教・政治・星占い、秘教 | 許可 | 今は止める理由が出ていない |

広告を見て「これは出したくない」と思ったら、そのカテゴリを足してこの表も直す。
