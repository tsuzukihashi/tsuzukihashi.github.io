# サイトの日本語 / 英語の出し分け

2026-10-17 から、サイト全体を **ブラウザの第一言語が日本語なら日本語、それ以外は英語** で表示する。
URL は1つのまま（`/en/` は作らない）。仕組みは `assets/js/lang.js` に全部ある。

- `?lang=ja` / `?lang=en` で明示指定できる。ナビ右端（ナビが無いページは右下）の切り替えボタンでも変えられ、選んだ言語は localStorage に残る
- 検索エンジンのクローラーには日本語（既定）を見せる
- 国（IP）では判定しない。GitHub Pages では国が取れないので、ブラウザの言語で決める

## ページの書き方

### 1. `<head>` に読み込む

`<meta charset>` と `<meta name="viewport">` の直後、スタイルシートより前に同期で読む:

```html
<script src="/assets/js/lang.js"></script>
```

あわせて英語のタイトルと説明を置く（英語表示のときに `document.title` と meta description を差し替える）:

```html
<meta name="title-en" content="September 2026 Revenue Report - Blog | Ryo Tsuzukihashi">
<meta name="description-en" content="...">
```

og:title / og:description は日本語のまま（SNS のクローラーは JS を動かさない）。

### 2. 本文は両方の言語を並べて書き、片方を隠す

```html
<!-- 短い文言 -->
<span class="i18n-ja">プライバシーポリシー</span><span class="i18n-en">Privacy Policy</span>

<!-- 長い本文はブロックごと二重にする -->
<div class="post-content i18n-ja"> ...日本語... </div>
<div class="post-content i18n-en"> ...English... </div>
```

- `.i18n-ja` は英語表示のとき、`.i18n-en` は日本語表示のときに `display:none!important` になる。
  見えている側は元の CSS の display のまま
- JS が無い環境では日本語だけが見える
- もともと英語の文言（ナビの Portfolio / About など）はそのまま
- 属性は `data-en-placeholder` / `data-en-alt` / `data-en-aria-label` / `data-en-title` / `data-en-src` に英語を書く
- **文字の入った画像も言語ごとに用意する**。日本語が焼き込まれた画像は `.i18n-ja` / `.i18n-en` の2枚にするか `data-en-src` で差し替える。
  App Store のスクショは US ストアの英語版を `assets/data/apps_en.json` の `screenshots` に持っている（`scripts/fetch_apps_en.py`）。
  トップの代表作カードの画像は `docs/works-kv.html` で作る
- 作ったら、英語表示で日本語が残っていないかを全ページ機械的に調べる（テキストだけでなく画像も目で見る）
- JS で文言を出すときは `window.tsuzukitLang`（`'ja'` か `'en'`）で分ける

### 3. 生成スクリプトがあるページは、スクリプト側に英語を持たせる

HTML を直接直すと、次に生成したときに消える。

| ページ | 生成元 |
|---|---|
| `blog/posts/income-report-YYYY-MM.html` | `docs/income-report/generate_articles.py`（英語は `months_en.py`） |
| `blog/posts/app-*.html` | `scripts/generate_app_blogs.py` |
| `portfolio/ranking/index.html` | `docs/build_ranking.py` |

## 英語の書き方

- 日本語を一語ずつ置き換えない。英語圏の個人開発者が読んで自然な文にする
- 一人称は I。数字・固有名詞・事実は日本語版と完全に同じにする。足さない、削らない
- アプリ名は App Store の英語名（`assets/data/apps_en.json`）を使う。**英語名が無いものも日本語のまま出さない。** 意味を訳した英語名を付ける（例: 馬券ジェネレーター → Betting Ticket Generator）。課金商品名・表の中の名前も同じ（2026-10-17、収益公開の明細表に日本語の商品名が残っていて指摘された）
- 金額は円のまま（¥）。ドル換算は書かない
- 法的文書の英語版には「日本語版が正本」の一文を入れる
- 日本語の文言は1文字も変えない

## 新しいページを作るとき

日本語と英語を最初から両方書く。片方だけで公開しない。
