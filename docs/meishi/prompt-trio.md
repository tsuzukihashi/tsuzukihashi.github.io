# 名刺の表の3キャラ（ChatGPT の Image への頼み方）

名刺の表の右半分に置く1枚の絵。もらった人の子どもが「かわいい」と思えて、
3人が「同じ人が作った仲間」に見えることが役目。キャラの姿はアプリのものから変えない。

添付する参照画像（白地にしたもの。`.playwright-mcp/meishi/`）

1. `ref-tsuzukit.png` … TsuzuKit のキャラ（`docs/meishi/parts/character-peek.svg` を書き出したもの）
2. `ref-unchikun.png` … うんちくん（PoopCounter `Poo/hi`）
3. `ref-mokumoku.png` … もくもく（BookBank `mokumoku_welcome`）

## 文面

```
添付の3枚はキャラクターの参照画像です。3人を1枚の絵に並べてください。新しいキャラとして描き起こさず、参照画像どおりの見た目で描いてください。

1枚目：真っ黒なシルエットのキャラ。口はなく、目は縦長の白い楕円が2つだけ。輪郭も黒一色で、線や陰影や光沢は入れない。
2枚目：ピンクのうんちのキャラ「うんちくん」。とがった巻きの頭、大きな白目に黒い瞳、小さく開いた口、両側の羽のような手、短い足。色と形はそのまま。
3枚目：クリーム色の雲のキャラ「もくもく」。弧の線2本の閉じた目、ピンクの頬、口はない。もくもくした輪郭と丸い手。色と形はそのまま。

場面：3人は仲良しの仲間。真ん中に黒いキャラが立って片手を上げてあいさつし、右にうんちくんが寄りそって手をふり、もくもくが2人の頭の少し上、左うしろにふわっと浮かんで手をふる。3人とも見る人のほうを向く。大きさは、黒いキャラを1とすると、うんちくん0.8、もくもく0.9くらい。
3人の描き方（輪郭のやわらかさ・塗りの平らさ・影の付け方）はそろえて、1枚の絵としてまとまりがあるようにしてください。ただし顔・色・体の形は参照画像から変えないでください。
背景はまっ白な無地。地面の影や飾り、文字は入れないでください。横長（4:3）。確認や質問はせず、画像を1枚だけすぐ作ってください。
```

## 結果

2026-11-20、1回目で採用。生成の原寸は `parts/trio-original.png`（1448x1086、白地）。
背景は端から届いた白（244以上）だけを透明にして `parts/trio.png`（1250x934）にした。
暗い地とクリーム地に乗せて、ふちに白が残っていないこと、TsuzuKit のキャラの白い目が残っていることを見た。
名刺の表では幅 44mm で使う（約 720dpi）。

## 2回目：一緒に何かしている10場面（2026-11-20）

1回目は「並べただけ」と言われた（描き方はそろっても、3人が何もしていない）。
3人の手や体が触れ合って、1つのことを一緒にしている場面を10個、1場面1会話で作った。
文面は共通の前置き（3人の姿・守るところ）＋場面1文＋共通の締め。場面の一覧は `collab/scenes.json`、10枚の一覧は `collab/sheet.jpg`。
生成の原寸（1448x1086）は `.playwright-mcp/meishi/collab/` にある。選ばれたものだけ `parts/` に入れる。
