この規約は、續橋涼（個人開発者 / TsuzuKit。以下「開発者」）が提供する iPhone アプリ「Qiita Book」（以下「本アプリ」）を使うときの決まりです。本アプリを使った時点で、この規約に同意したものとします。免責事項は第7条にあります。

第1条（適用）

この規約は、本アプリを使うすべての方（以下「利用者」）に適用されます。本アプリは App Store から配信しており、Apple が定める標準のライセンス契約（EULA）もあわせて適用されます。この規約と EULA が食い違うときは、この規約を優先します。

第2条（Qiita との関係）

  • 本アプリは個人開発のアプリで、Qiita 株式会社が作ったものでも、認めたものでもありません
  • 記事の取得・検索・ストック・いいね・コメント・投稿には、Qiita 株式会社が公開する Qiita API v2 を使います。Qiita の仕様変更や API の停止により、本アプリの機能が使えなくなることがあります

第3条（利用のしかた）

本アプリに会員登録はありません。記事を読むだけなら Qiita のアカウントは不要です。ストック・いいね・コメント・投稿には Qiita でのログインが必要です。記事の取得にはインターネット接続が必要です。

第4条（広告と「広告を非表示にする（買い切り）」）

  • 本アプリは、記事一覧の間の広告と、Widget から記事を開くときの動画広告によって運営しています
  • 「広告を非表示にする（買い切り）」は、App Store を通じて一度だけお支払いいただく購入です。購入すると、記事の間の広告と動画広告が表示されなくなります。月々の支払いはなく、自動更新もありません
  • 価格は App Store と本アプリの画面に表示されるものが正です
  • 購入の記録は Apple ID に紐づきます。機種変更やアプリの再インストールのあとは、同じ Apple ID で「購入を復元する」を押してください

  • 以前の月額サポータープラン（自動更新）に加入中の方は、加入している間は広告が表示されません。解約は iPhone の「設定 → Apple アカウント → サブスクリプション」から行えます。解約後に広告を消すには、買い切りをご購入ください
