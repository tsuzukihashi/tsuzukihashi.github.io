プライバシーポリシー

Qiita Book（旧 WidgetQiita）／制定日 2026年11月6日

このポリシーの要旨
Qiita Book に会員登録はなく、開発者が氏名やメールアドレスを尋ねることはありません。閲覧履歴・マーカー・下書き・Widget の設定はあなたの iPhone の中に保存します。 Qiita でログインすると、Qiita が発行したアクセストークンを iPhone の中（Keychain）に保存し、記事の取得やストック・投稿のときに Qiita のサーバーへ送ります。 広告（Google AdMob）、利用状況の計測（Firebase Analytics）、課金の管理（RevenueCat）のために、それぞれのサービスへ情報が送られます。開発者が自分のサーバーを持って情報を集めることはありません。

2. 端末の中だけで扱うもの

閲覧履歴・統計アプリの中で開いた記事、その記事のタグと投稿者（「よく見るタグ・ユーザー」に使います）
マーカー本文で選んだ言葉と、その前後の文字、記事の題名とリンク
下書き投稿の途中の題名・本文・タグ
Widget の設定お気に入りタグの名前
アプリの状態Widget から無料で開いた回数、広告を非表示にする権利の有無、チュートリアルを見たか
キャッシュ一度表示した記事の本文と画像（通信を減らすために端末に残します）

これらは開発者のサーバーへ送られません。アプリを削除すると消えます。

3. Qiita に送るもの

記事の一覧・本文・検索・コメントは、Qiita 株式会社が公開している Qiita API v2 から取得します。取得のときに、お使いの端末の IP アドレスなどが Qiita のサーバーに届きます。

Qiita でログインしたとき。ログインは Qiita のページ（OAuth）で行い、アプリが Qiita のパスワードを受け取ることはありません。Qiita が発行したアクセストークンを iPhone の Keychain に保存し、フォロー中タグの新着・ストック・いいね・コメント・記事の投稿と編集・自分の記事の取得のときに Qiita へ送ります。 ログアウトするとトークンは端末から消えます。Qiita 側の連携も解除したいときは、Qiita の「設定 → アプリケーション」から解除できます。Qiita での情報の扱いは Qiita のプライバシーポリシー をご覧ください。

アクセストークンを直接貼り付けてログインする方法も用意しています。このときも、トークンは Keychain に保存し、Qiita 以外には送りません。

4. 広告（Google AdMob）

記事一覧の間の広告と、Widget から記事を開くときの動画広告に、Google LLC の AdMob を使っています。広告の配信のために、Google に端末の情報（端末の種類、OS のバージョン、IP アドレス、広告識別子など）が送られます。

  • 初回起動時に iOS の「トラッキングの許可」を尋ねます。許可したときだけ、広告識別子（IDFA）を広告の最適化に使います。許可しなくてもアプリは使えます（広告は出ますが、あなたに合わせた広告ではなくなります）
  • 許可は、iPhone の「設定 → プライバシーとセキュリティ → トラッキング」からいつでも変えられます
  • Google での情報の扱いは Google のプライバシーポリシー をご覧ください
  • 「広告を非表示にする（買い切り）」を購入すると、記事の間の広告と動画広告は表示されなくなります

5. 利用状況の計測（Firebase Analytics）

どの機能がどれくらい使われているかを知るために、Google LLC の Firebase Analytics を使っています。画面を開いた回数などの統計と、端末の種類・OS のバージョン・アプリのバージョン・Firebase が作るアプリ単位の識別子が送られます。氏名やメールアドレス、記事の本文、マーカーの言葉は送りません。

6. 課金の管理（RevenueCat）

「広告を非表示にする（買い切り）」と、以前の月額サポータープランの購入状態の管理に、RevenueCat, Inc. のサービスを使っています。購入は Apple の App Store で行われ、Apple が発行する購入の記録（レシート・取引 ID）と、RevenueCat がこの端末のために作る匿名の識別子が RevenueCat に送られます。氏名・メールアドレス・カード情報は送られません（カード情報は Apple だけが扱います）。

RevenueCat での情報の扱いは RevenueCat のプライバシーポリシー をご覧ください。

7. 使わないもの

位置情報、連絡先、写真、カメラ、マイク、ヘルスケアのデータは使いません。開発者が自分のサーバーに利用者の情報を集めることはありません。

8. 情報を使う目的

  • Qiita の記事を読む・探す・ストックする・投稿するため
  • 閲覧履歴・統計・マーカー・下書きを端末の中で見返せるようにするため
  • 広告を表示するため、および購入した方に広告を表示しないため
  • どの機能が使われているかを知り、アプリを良くするため
  • お問い合わせに答えるため

これ以外の目的には使いません。法令にもとづく場合を除き、本人の同意なく第三者に渡すこともありません。

9. 海外への送信

Google LLC と RevenueCat, Inc. はアメリカの事業者で、情報はアメリカなどのサーバーで扱われることがあります。Qiita 株式会社は日本の事業者です。

10. 消したいとき

  • アプリを削除すると、端末の中の閲覧履歴・統計・マーカー・下書き・設定・キャッシュ・アクセストークンはすべて消えます
  • 購入の記録は Apple ID に紐づいています。同じ Apple ID で入れ直せば「購入を復元する」で戻せます
  • Qiita との連携は、Qiita の「設定 → アプリケーション」から解除できます
  • Google・RevenueCat に送られた情報の扱いは、それぞれのポリシーに従います。個別の削除を希望される場合は、下のお問い合わせ先までご連絡ください
